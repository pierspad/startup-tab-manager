Startup Tab Manager

Configure windows and tabs to restore automatically on browser startup

Private Windows Permission Required: Private windows will NOT be restored unless allowed in Firefox settings. Open about:addons → click Extensions in the left menu → select Startup Tab Manager → and toggle "Run in Private Windows" to Allow.
